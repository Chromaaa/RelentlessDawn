# Relentless Dawn

A hardcore-focused Project Zomboid server experience built around survival, progression, and community-driven gameplay.

---

## 🌍 Overview

Relentless Dawn is a custom-configured Project Zomboid server designed to be more challenging, immersive, and progression-based than standard gameplay. The server emphasizes survival realism, long-term persistence, and meaningful player decisions.

This repository contains server configurations, mod settings, and gameplay adjustments used to run the Relentless Dawn experience.

---

## 🔧 Features

* Hardcore survival tuning
* Extended progression pacing
* Custom infection & medical tweaks
* Reworked revive and recovery systems
* Dynamic world events (hordes, weather, etc.)
* PvE-focused gameplay with optional PvP systems
* Quality-of-life improvements for long-term play

---

## 🧠 Gameplay Philosophy

Relentless Dawn is built around three core ideas:

* **Survival has weight** — mistakes matter and recovery takes time
* **Progress is earned** — resources, safety, and power come slowly
* **The world doesn’t wait for you** — events continue whether you’re ready or not

---

## ⚙️ Key Server Settings

* PvP: Disabled (PvE focus)
* Global Chat: Enabled
* Empty Server Pause: Enabled
* Custom revive/recovery system tuned for extended survival cycles
* Modified infection mechanics and antidote systems

---

## 🧩 Mods

A curated modlist is used to support stability, immersion, and gameplay depth. Mods are balanced to avoid overpowering vanilla survival mechanics.

Relentless Dawn is actively maintained and updated. Balance changes, systems tweaks, and content expansions are introduced regularly based on player feedback.
